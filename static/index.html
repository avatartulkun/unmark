去掉导出文件右下角的固定角标

不靠内置模板图。水印的定义就是「内容在变、它不变」——把若干页叠起来求交集，在几乎每一页同一坐标都成立的，才算水印。换字体、换版本、换成别家的角标，都还认得出来。

PDF 与 PPTX 只动那一小块，其余逐位不变 写出后重新打开复核 原始文件永不改写

把 PDF 或 PPTX 拖到这里，或点击选择

PDF：整页是一张图的效果最好，有文字层的页会自动跳过
PPTX：水印是对象就直接删掉（无损）；每页是整张图就按 PDF 那一套修

还有一层淡淡的底色没去掉？

在下图上拖一个框，把那片发灰／发亮的区域圈进去，宁可框大一点。框外的画面一个像素都不会动。

它去的是哪一种水印

能处理

  • 位置固定、几乎每页都在的角落标记
  • 深色、浅色、半透明，以及彩色角标
  • 角标背后那层磨砂衬底

不处理

  • 铺满整页的斜纹水印
  • 位置每页都变，或只在少数页出现的
  • 有文字层的 PDF 页（会自动跳过）

它怎么知道哪一块是水印

三路投票，先看暗、再看亮度反差、最后看颜色。

  • 暗像素跨页交集 —— 深色角标
  • 局部反差跨页交集 —— 浅色、半透明、深底白字
  • 色度跨页交集 —— 颜色不同但一样亮的角标

定位之后还有一步削形，把掩膜削回字形，实测涂改面积少三成。

命中区域超过整页 0.5%，或包围盒不像一行角标，一律判为误检并中止。宁可不处理，也不乱涂。

怎么补上被涂掉的那一块

三档，按底色的复杂程度往下退：

  • 纯色铺底 —— 像素级完美
  • 渐变曲面 —— 二次曲面外推
  • inpaint —— 并补回颗粒

角标背后那层「磨砂」

它不是一层半透明色板，是把底下的画面做了高斯模糊。

模糊丢掉的高频找不回来；能做的是从板外把结构续进去，横向不连贯的页面则保持原样。

PPTX 有两种长相

工具会自动分辨，你不用管：

长相 水印是什么 怎么处理
正常的幻灯片 一个形状对象 直接删掉，无损
每页就是一整张图 烧在像素里 和 PDF 一样处理

删对象那条路会把候选列出来给你看，压在正文区里的默认不动。

不支持老的 .ppt，请先另存为 .pptx。

不会把你的文件搞坏

  • 原始文件永不改写
  • 掩膜外像素强制还原并断言，PNG 无损往返核对
  • 写出后重新打开抽页复核
  • PPTX 只删判定的那几个对象，复核不过就删掉输出

已知做不到的

  • 完全不透明的那部分找不回来
  • 磨砂衬底只在画面横向连贯时才能续接
  • 输出 PDF 通常比原件大（1.2～5 倍）

你的文件去了哪里

不想让文件离开自己的电脑，就跑在本机：

python3 -m pip install -r requirements.txt
python3 server.py

本机模式只监听 127.0.0.1。
